# browserwright

This installed skill is only a stable discovery and permission shell. The authoritative instructions are generated by the installed `browserwright` CLI so they match the package, daemon, primitive surface, and extension version in use.

Before doing browser work:

```bash
browserwright version check
browserwright --print-skill
```

Follow the generated `browserwright --print-skill` output for command forms, session rules, primitives, userscripts, trust boundaries, and recovery behavior.

Also read `memory.md` in this skill directory before choosing a backend. It records the user's backend preferences and scenario decisions.
